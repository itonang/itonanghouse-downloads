# 이토낭하우스 다운로드

[이토낭하우스](https://www.itonanghouse.kr/)에서 배포하는 프로그램의 설치 파일 보관소예요.
파일은 [Releases](https://github.com/itonang/itonanghouse-downloads/releases)에 있고, 사이트의 다운로드 버튼이 이곳 파일을 가리켜요.

- 최애와 함께 — 모니터 여백에 최애를 스티커처럼 붙여두는 프로그램
- 이거 하고있어! — 디스코드 프로필의 '○○ 하는 중' 상태를 꾸미는 프로그램

프로그램 소개, 사용법, 문의는 사이트에서 확인해 주세요.
이 저장소에는 설치 파일만 있고, 프로그램 소스 코드는 공개하지 않아요.
